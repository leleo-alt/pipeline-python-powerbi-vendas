# 🚀 Pipeline de Automação de Dados: Python + Power BI

Este projeto demonstra a criação de uma **pipeline de dados completa**, integrada do backend à visualização de inteligência de negócios.

---

## Tecnologias Utilizadas
* **Python**: Automação, criação de dicionários e manipulação de arquivos CSV.
* **VS Code**: Ambiente de desenvolvimento.
* **Power BI Desktop**: Tratamento final de visualização, modelagem e criação de gráficos/cartões KPI.

---

## Funcionalidades do Script Python
1. **Modelagem dos dados**: Estruturação de dados fictícios de vendas com informações geográficas (Fortaleza e Caucaia).
2. **Exportação segura**: Gravação em formato CSV utilizando delimitador `;` e codificação `utf-8-sig` para compatibilidade total de caracteres com o Power BI no padrão brasileiro.

---

## Dashboard no Power BI
O painel foi construído para responder a perguntas estratégicas de negócio:
* **Métrica principal (KPI)**: Valor total de vendas acumulado.
* **Análise por região**: Percentual de receita gerada entre Fortaleza e Caucaia.
* **Performance de produtos**: Volume de cursos vendidos por categoria.
